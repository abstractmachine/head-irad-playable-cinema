# Theory
This folder collects conceptual notes, thematic essays, and curated source material that inform the Playable Cinema project. It is a working space for framing ideas, tracking readings, and collecting quotes and texts that shape design and research.

## Purpose
- Document themes, arguments, and theoretical context for the project.
- Keep an organized bibliography / excerpts for easy reference while developing.
- Provide a place for short essays, annotated notes, and synthesis of readings.
