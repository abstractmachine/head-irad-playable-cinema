# Code

A collection of tools for creating and playing interactive, branching video experiences.

## Projects

- **[crossing-tool](crossing-tool/)** — The current multi-tool for the Playable Cinema project. A CLI + GUI application for importing media, detecting shots, running AI annotation, and synchronizing gameplay with cinema. All models run locally. This is the active codebase.

## Legacy / Archive

The [`archive/`](archive/) folder contains earlier prototype tools that have been superseded by `crossing-tool`. They are kept for reference but are no longer maintained.

Notable archived projects:

- **[playable-tool](archive/playable-tool/)** — Earlier desktop annotation tool (PyQt5 GUI + CLI). Replaced by `crossing-tool`.
- **[playable-blip-player](archive/playable-blip-player/)** — Early BLIP-based captioning and playback prototype.
- **[playable-dual-player](archive/playable-dual-player/)** — Dual-video sync player prototype.
- **[playable-cinematheque](archive/playable-cinematheque/)** — Early cinematheque/database prototype.
- **[inside-inside](archive/inside-inside/)** — Original *Inside* ↔ cinema dataset and playback experiments.
- Other tools (`playable-annotate`, `playable-captions-*`, `playable-grid`, `playable-local`, `playable-playback`, `playable-trainer-yolo`, `joycaptions`, etc.) — Various single-purpose scripts and experiments from earlier stages of the project.
