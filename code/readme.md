# Code

A collection of tools for creating and playing interactive, branching video experiences.

## Projects

- **[playable-tool](playable-tool/)** - Desktop application for annotating videos with AI-powered scene detection and metadata tagging
- **[playable-nickelodeon](playable-nickelodeon/)** - Web-based interactive video player with branching narratives
- **[playable-dual-player](playable-dual-player/)** - Dual-screen video player with synchronized playback and search capabilities
- **[video-converter](video-converter/)** - Utility scripts for video format conversion

Each project contains its own readme with detailed setup and usage instructions.
