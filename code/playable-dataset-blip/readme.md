# Blip Dataset Maker
This takes the designated `/Dataset` folder, creates a Dataset out of the of `jpg` + `txt` entries.

## Pyenv
```
$ cd ./code/playable-dataset-blip
$ pyenv virtualenv 3.11.9 playable-dataset-blip
```

To activate :

```
$ pyenv activate playable-dataset-blip
```

## Dependencies
```
$ pyenv virtualenv 3.11.9 playable-dataset-blip
$ pyenv activate playable-dataset-blip
$ pip install datasets
$ pip install Pillow
```
