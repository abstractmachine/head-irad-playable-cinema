# Video

## Converter
There is a shell script for optimizing the videos for optimized playback on most modern machines (Mac/Windows/Linux) and Raspberry PI. I have already activated fast scrubbing and quick loading options in this converter.

Cf. [convert.sh](./convert.sh)

To execute, you have to make this script executable :

```
$ chmod +x convert.sh
```

To run:

```
$ ./convert.sh
```
