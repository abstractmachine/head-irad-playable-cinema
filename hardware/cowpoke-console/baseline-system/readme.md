# Playable Cinema – System Baseline (Blackwell)

This folder documents the system configuration used for GPU-based
image analysis and real-time inference.

Key characteristics:
- GPU: NVIDIA RTX PRO 4500 (Blackwell)
- CUDA: 13.2
- PyTorch: compiled from source with sm_120 support
- OS: Ubuntu 24.04
