# Dataset

## Inside
Our datasets are being labelled by [Faust Perillaud](.) over at Roboflow. For now, we are only exploring labelled datasets on the game [Inside](https://www.playdead.com/games/inside/) by [Playdead](https://www.playdead.com).

## How To Annotate
1. Go to [Roboflow Playable Cinema](https://app.roboflow.com/testplayablecin/playable-cinema/overview) Project space on Roboflow.
2. Sign-in
3. Open [Playable Cinema](https://app.roboflow.com/testplayablecin/playable-cinema/models) Models tab
4. Select `Upload Data`
5. Upload video clip of [Inside](https://playdead.com/games/inside/) playthrough
	a. Select part of clip to annotate
	b. Select sample rate which will convert video into still frames
6. Create a `Batch Name`

## Download Dataset
For example, to custom train on our own locally or on Colab.

1. Go to [Roboflow Playable Cinema](https://app.roboflow.com/testplayablecin/playable-cinema/overview) Project space on Roboflow.
2. Sign-in
3. Open [Playable Cinema](https://app.roboflow.com/testplayablecin/playable-cinema/models) Models tab
4. Select `Dataset`
5. Select prefered `Version` (usually latest date)
6. Select `Download Dataset`
